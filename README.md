# جزوه جاوااسکریپت — Next.js + TypeScript + Tailwind

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
```

- `scripts/convert.mjs` : تبدیل `data.js` قدیمی به `src/data/topics.json` (`npm run convert -- مسیر/data.js`)
- برای افزودن مبحث جدید، یک آیتم به `src/data/topics.json` اضافه کنید.
