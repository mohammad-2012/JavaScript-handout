# پروژه مودال باکس

این پروژه فقط شامل کدهای اچ‌تی‌ام‌ال و سی‌اس‌اس برای ساختار و ظاهر یک مودال باکس ساده میباشد.

> ⚡ تو این فایل هیچ کدی از جاوااسکریپت وجود نداره و خودت باید طبق آموزش کدشو بنویسی.

---

## در ویدیوی آموزشی

تو دوره‌ی خوره جاوااسکریپت، مرحله به مرحله کدهای جاوااسکریپت رو اضافه میکنیم و با استفاده از مفاهیم شیءگرایی یک مودال باکس حرفه‌ای و تعاملی میسازیم.

---

## نکته

برای عملکرد کامل مودال، حتماً ویدیوی آموزشی رو دنبال کن و کدهای جاوااسکریپت رو طبق آموزش اضافه کن.
